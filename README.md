# 📊 Exploratory Data Analysis on Online Retail Dataset

## 🔗 Project Overview
This project presents a comprehensive Exploratory Data Analysis (EDA) of a real-world Online Retail dataset. The analysis focuses on understanding customer purchasing behavior, transaction patterns, and key business insights using Python and SQL.

The project is divided into two major analytical components:
- 📌 Python-based EDA (using Google Colab)
- 📌 SQL-based data analysis

---

## 🎯 Objectives
- Analyze customer purchasing behavior
- Identify top-selling products and high-value customers
- Understand sales trends and seasonality
- Perform data cleaning and preprocessing
- Apply SQL queries for structured data analysis

---

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL
- Google Colab
- Excel (for initial data handling)

---

## 📂 Dataset Description
The dataset contains transactional data of an online retail store, including:
- Invoice details
- Product descriptions
- Quantity purchased
- Unit price
- Customer IDs
- Country

### 📁 Data Splitting
To improve analysis and structure, the dataset was divided into:
- **Full Dataset** – Complete transactional data
- **Customer Dataset** – Customer-focused data for behavioral analysis

---

## 🧹 Data Cleaning & Preprocessing
- Removed missing/null values
- Handled duplicate records
- Filtered invalid transactions (e.g., negative quantities)
- Converted data types for accurate analysis

---

## 📊 Analysis Performed

### 🔹 Python (Google Colab)
- Sales trend analysis over time
- Top-selling products
- Revenue distribution
- Country-wise sales analysis
- Data visualization using charts and graphs

### 🔹 SQL Analysis
- Customer segmentation
- Revenue aggregation
- Top customers by spending
- Product-level performance analysis
- Use of joins, grouping, and filtering

---

## 📈 Key Insights
- A small group of customers contributes significantly to total revenue
- Certain products dominate sales volume
- Sales show time-based patterns indicating seasonality
- Transactions are concentrated in specific regions
